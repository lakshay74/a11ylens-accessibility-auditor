A TRANSPARENT MEASURE

A direction, not a verdict.

The A11yLens score starts at 100 and subtracts a penalty for each axe rule: critical 12, serious 8, moderate 4, minor 1, multiplied by up to five affected elements for that rule. The score stops at 0. Unknown impact uses the minor weight.

Counts use axe-core’s affected-element total. One element can be affected by multiple rules. This estimate helps prioritize work; it is not a WCAG conformance rating.

THE CALCULATION max(0, 100 − Σ impact weight × min(elements, 5))
