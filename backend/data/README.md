# WCAG summary corpus

`wcag.json` contains 55 success criteria at WCAG 2.2 conformance levels A and AA. Each record includes a short, plain-language summary and a link to its W3C WAI Understanding page.

The corpus is generated by `backend/scripts/build_wcag_corpus.py`. Run it from the project root when you want to refresh the checked-in data. The script makes read-only requests to public W3C pages and writes the summarized records to `wcag.json`.

W3C describes Understanding documents as informative guidance, not the normative WCAG standard. Use the links for context and review the applicable criterion and page manually before drawing a conformance conclusion. W3C's reuse and licensing terms apply to source material.
